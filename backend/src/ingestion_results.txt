SCALING CONSIDERATIONS
----------------------

For a much larger corpus such as 4,000+ documents, the ingestion process
should become resumable and observable.

Useful improvements include:

- Process documents incrementally instead of loading everything into memory.
- Maintain a manifest of processed files.
- Skip already successfully processed files during re-runs.
- Record failures with filenames and error messages.
- Log ingestion progress.
- Persist ingestion status so a crash does not require restarting from zero.
- Periodically report document and chunk counts.

The same completeness principle should remain:

source files =
successful documents + recorded failures
