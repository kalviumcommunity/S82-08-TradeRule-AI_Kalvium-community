TRADE RULE AI APPLICATION
-------------------------

Source metadata will allow future answers to cite the document
from which retrieved compliance information originated.

Position metadata can later support more precise source
references and debugging.

Additional metadata such as page number, section heading,
effective date, or source URL can be added when those fields
are available in the original documents.

Metadata can also support future retrieval filtering, such as
restricting results to a particular document type or policy
version.
