OBSERVATIONS
============

The unfiltered vector search searches the entire corpus and
returns five semantically similar chunks.

The metadata filter restricts retrieval to the "export compliance"
section. This removes unrelated sections and improves retrieval
precision for this specific query.

Vector search focuses on semantic similarity, while keyword
matching rewards exact terms appearing in the text.

Hybrid search combines both approaches. It can be useful when
exact terms such as product names, policy IDs, error codes,
classification terms, or other identifiers are important.

The current hybrid implementation uses a simple keyword-count
score combined with the vector similarity score.

A production implementation could normalize lexical and vector
scores before combining them.

compliance information before passing context to the language
