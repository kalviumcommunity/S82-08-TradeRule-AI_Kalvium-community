3.20 Text Extraction & Cleaning Pipeline
=========================================

Purpose:
Clean raw extracted documents before downstream RAG processing.

Cleaning steps:
- Unicode normalization using NFKC
- Common mojibake/encoding artifact repair
- Line-ending normalization
- Page X of Y boilerplate removal
- Repeated document header/footer removal
- Whitespace and tab normalization
- Excessive blank-line removal

Documents processed:
- customs_requirements.txt
- export_guidelines.md
- import_rules.html
- shipment_compliance.pdf

Edge Case:
----------
HTML extraction can place page markers and repeated headers inline
instead of on separate lines. The pipeline handles both standalone
and inline boilerplate.

RAG Impact:
-----------
Cleaning before chunking and embedding reduces retrieval noise.
This helps prevent repeated headers, page markers, and formatting
artifacts from becoming irrelevant embedding content.
