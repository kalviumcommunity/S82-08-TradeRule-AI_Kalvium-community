CHOSEN PROMPT
-------------
The clear/constrained prompt was selected.

WHY IT WORKS BETTER
-------------------
The second prompt is more reliable because it explicitly defines the task,
the number of items, the expected explanation, the output format, and the
maximum length. The vague prompt leaves these decisions to the model,
which can produce inconsistent structure and level of detail.

The system prompt additionally defines TradeRule AI's role, scope, tone,
response length, and fallback behaviour when sufficient information is
not available.
